# Design Brief

## Product purpose

在本机通过 Clash Verge 的控制器 API 定时检测台湾叶子节点，把最近状态和 24 小时质量趋势集中到一个低占用的本地监控卡片中。

## Primary user

需要长时间使用 Clash Verge、希望快速判断哪个台湾节点当前稳定的个人用户，主要在 Windows 桌面上查看置顶小窗。

## Principles

1. 先显示可用性，再显示细节：用户先回答“现在能不能用”，再判断“哪个节点更好”。
2. 数据比装饰重要：颜色只表达状态，时间序列保留真实采样，不用无意义的动画和装饰。
3. 监控不能成为负担：本地 API、低频采样、固定内存占用和按期清理优先于功能堆叠。
4. 显式授权才改变路由：自动路由默认关闭；用户开启后，绿色当前节点保持不动，橙色按确认次数切换，首次超时/错误且有绿色候选时立即故障转移，并把实际结果回读展示。

## Success metric for the surface

用户打开卡片后 10 秒内能看懂最近一次采样的可用节点、超时节点和刷新时间，并能在 30 秒内通过 24 小时图定位明显不稳定的节点。

## Out of scope

- 不修改或注入 Clash Verge 的原始界面。
- 不注入或改造 Clash Verge 原始界面；不重启 Clash，不修改磁盘代理配置。运行中的节点切换只允许由用户显式开启的本地控制器 API 路由执行。
- 不上传监控数据，不依赖 AI 常驻运行。
- 首版不做云端同步、账号体系和复杂告警编排。
