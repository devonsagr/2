# 独立版前端视觉方向

## 方向

“夜间铁路调度板”：把当前有效节点、实际出站节点和历史采样读成一张值班面板。视觉上使用深石墨表面、钢灰文字、细线轨道和单一信号琥珀色；绿色、橙色、红色只承担健康状态含义。

这不是把原卡片放大成一个新壳，而是将其从 Obsidian 的通用卡框、纸签和桥接语境里脱离出来。独立软件的首屏必须直接回答三件事：现在有多少节点可用、Clash 实际在用谁、质量趋势是否越过阈值。

## 首屏结构

1. 顶部工具栏：产品名、服务状态、最近刷新、立即刷新。
2. 主信号带：可用节点数为第一视觉焦点；平均延迟、可用率和 Clash 当前节点作为同一行的决策上下文。
3. 趋势轨道：默认显示 24 小时最佳可用延迟，阈值为实线/虚线对照；Timeout 和错误断线，不连接成假线。
4. 节点清单：用文字状态、数值和小圆点共同表达，优先显示当前节点和异常节点。
5. 配置抽屉：自动路由的开关、阈值、采样周期和节点筛选集中管理，默认收起。

## 记忆点

“当前节点—健康判定—趋势窗口”沿着一条连续的信号带排列；用户不需要先打开设置或读装饰性说明，就能从当前节点继续追溯到历史异常。

## 必须保留

- 独立于 Obsidian，直接消费当前 loopback API。
- 默认只读；自动路由必须显式开启并沿用后端安全合同。
- 真实采样、空态、离线、采样中、暂停、错误和历史缺失都要有对应界面。
- 无外部字体、图片、账号、云端请求和 Node 运行时依赖。
