# 独立版前端视觉方向

## 方向

“夜间铁路调度板”：把当前连接、健康判定和历史采样读成一张值班面板。深色主题使用深石墨表面、钢灰文字、细线轨道和单一信号琥珀色；浅色主题使用雾灰背景、白色面板和同一套语义色。

独立软件的首屏必须直接回答三件事：现在有多少节点可用、控制器是否已连接、质量趋势是否越过阈值。连接失败时，用户应该知道下一步是展开连接设置，而不是猜测网页为什么空白。

## 首屏结构

1. 顶部工具栏：产品名、服务状态、最近刷新、主题切换和立即刷新。
2. 主信号带：可用节点数为第一视觉焦点；平均延迟、可用率和当前节点作为决策上下文。
3. 趋势轨道：默认显示最佳可用延迟；Timeout 和错误断线，不连接成假线；导出按钮紧邻趋势控制。
4. 节点清单：用文字状态、数值和小圆点共同表达，优先显示当前节点和异常节点。
5. 配置区：连接高级设置、采样参数、自动路由和手动节点清单集中管理，默认收起连接细节。

## 必须保留

- 自动连接状态、连接测试和可解释的错误反馈。
- 深色/浅色主题，主题选择在本机记忆且不依赖网络。
- 默认只读；自动路由必须显式开启并沿用后端安全合同。
- 真实采样、空态、离线、采样中、暂停、错误和历史缺失都要有对应界面。
- 无外部字体、图片、账号、云端请求和 Node.js 运行时依赖。
